# 🌟 Web & Mobile Developer Portfolio

Welcome to my **personal portfolio website**, showcasing my work as a **Web and Mobile Application Developer**.  
This project highlights my skills, projects, and experience through a clean, responsive, and modern design.

---

## 📖 About the Project

This portfolio website is designed to serve as a digital resume and showcase of my technical expertise.  
It’s built with simplicity, performance, and responsiveness in mind — making it accessible across desktop and mobile devices.

---

## 🚀 Features

- 🏠 **Intro Page** – A short professional introduction with my name, role, and background
- 💼 **Work Experience Page** – Highlights my past roles, key responsibilities, and achievements
- 🎓 **Education Page** – Lists my academic background and qualifications
- 🧰 **My Services Page** – Details the development and design services I provide
- ⚙️ **Skills Page** – Displays my technical skills and proficiencies
- 🧪 **Project Demo Page** – Showcases live projects and includes a video demo
- 📞 **Contact Page** – Provides multiple ways to connect with me
